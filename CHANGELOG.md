# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-13

Initial public release of the `swift-testing-agent` skill content.

### Covers

- Strict Swift Testing-first guidance for AI coding agents
- Required usage of `@Test` and `#expect` patterns
- Guidance for descriptive assertion messages
- Async testing patterns with `async`/`await`
- Parameterized testing patterns with `@Test(arguments:)`
- Callback/delegate testing patterns using `confirmation`
- Anti-pattern guidance for avoiding legacy XCTest usage
- Migration reference for converting XCTest tests to Swift Testing
- Realistic example scenarios for networking, view models, repository/service flows, and async services
