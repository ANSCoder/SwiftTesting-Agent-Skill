# Swift Testing — Claude Code Instructions

When writing Swift tests in this project, read `swift-testing-skill/SKILL.md` and all files
in `swift-testing-skill/patterns/` before generating any code. Follow every rule exactly.

Never generate XCTest patterns. See `swift-testing-skill/anti-patterns/xctest-leftovers.md`
for the full list of what to avoid.

For migration of existing XCTest code, use `swift-testing-skill/migration/xctest-to-swift-testing.md`.
