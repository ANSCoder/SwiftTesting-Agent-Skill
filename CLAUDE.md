# Swift Testing — Claude Code Instructions

When writing Swift tests in this project, read `SKILL.md` and all files
in `patterns/` before generating any code. Follow every rule exactly.

Never generate XCTest patterns. See `anti-patterns/xctest-leftovers.md`
for the full list of what to avoid.

For migration of existing XCTest code, use `migration/xctest-to-swift-testing.md`.
