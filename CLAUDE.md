# Swift Testing — Claude Code Instructions

When writing Swift tests in this project, read `skill/SKILL.md` and all files
in `skill/patterns/` before generating any code. Follow every rule exactly.

Never generate XCTest patterns. See `skill/anti-patterns/xctest-leftovers.md`
for the full list of what to avoid.

For migration of existing XCTest code, use `skill/migration/xctest-to-swift-testing.md`.
